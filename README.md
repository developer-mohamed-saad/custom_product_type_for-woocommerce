<h1>Custom Product Type for WooCommerce (Add-Ons, Data, Options, Booking, and Appointments)</h1>
<h3>== Description ==</h3>
Combine Add-Ons, Data, Options, Booking, and Appointments to create custom WooCommerce products. Revolutionize your store's possibilities!

<p>The <strong>Custom Product Type for WooCommerce</strong> plugin is your ultimate tool for crafting unique product types with advanced features. By integrating add-ons, data options, and booking functionalities, it caters to businesses looking for customization, control, and seamless user experience. Whether it's selling <strong>books, tickets, classes, or appointments</strong>, this plugin delivers everything you need for a dynamic WooCommerce store. 💡</p>

<p>With this plugin you can create multiple product types with diffrent data, addons , options and featrues. Also you can use the product categories and attributes in addons fields.</p>

<p><strong>Multilingual and Translation-Ready:</strong> The plugin is fully compatible with translation plugins like WPML, making it effortless to create a multilingual WooCommerce store. Deliver a localized experience to your customers in any language.</p>

<p><strong>Payment Gateway Compatibility:</strong> Seamlessly works with all WooCommerce payment gateways. The plugin integrates custom fields into the single product page, ensuring no limitations on payment or checkout options.</p>

<h3>Key Features</h3>
<h4>Free Features:</h4>
<p>Sutable for creating product data option to be displayed in and managed through the custom product type tab.</p>
<ul>
  <li><strong>Custom Product Types:</strong> Easily create tailored product types for your store.</li>
  <li><strong>Custom Taxonomies:</strong> Organize and categorize products effectively with additional taxonomy options.</li>
  <li><strong>Custom Badges:</strong> Highlight specific product types with labels such as "Exclusive" or "Best Seller."</li>
  <li><strong>Shortcode Integration:</strong> Display custom product types anywhere on your site using: <code>[cwpt_products product_type="your_product_type"]</code></li>
  <li><strong>Data Placement Control:</strong> Place fields in key locations on product pages:
    <ul>
      <li>Before/after the product title.</li>
      <li>Before/after the "Add to Cart" button.</li>
      <li>Before/after product meta.</li>
    </ul>
  </li>
  <li><strong>Custom Tabs in WooCommerce Admin:</strong> Add WooCommerce-compatible fields to admin tabs, enabling advanced data options for each product type. Available fields include:
    <ul>
      <li>Text</li>
      <li>Textarea</li>
      <li>Select</li>
      <li>Radio</li>
      <li>Checkbox</li>
    </ul>
  </li>
  <li><strong>Show/Hide from Shop Pages:</strong> Choose whether to display custom product types on shop pages or not.</li>
</ul>

<h4>Premium Add-On Features:</h4>

  <li><strong>Radio Buttons:</strong> Simplify single-choice options (e.g., "Basic" vs. "Premium").</li>
  <li><strong>Textarea:</strong> Collect detailed instructions or notes (e.g., "Special Instructions").</li>
  <li><strong>Other Fields:</strong>
    <ul>
      <li>Link</li>
      <li>Price</li>
      <li>Email</li>
      <li>Color Picker</li>
      <li>File Upload</li>
      <li>WYSIWYG Editor</li>
      <li>Date Picker</li>

      <li>Taxonomy Fields: Select Taxonomy, Radio Taxonomy, Multicheck Taxonomy, etc.</li>
    </ul>
  </li>
</ul>
